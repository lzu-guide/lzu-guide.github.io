# 兰大物理退役复学学长的推免复盘：从基础重修到夏令营考核的思考与建议
> **基本情况**：
>
> + **本科院校**：兰州大学 物理科学与技术学院 物理学（磁学）专业
> + **学业情况**：专业排名 1/42，GPA 4.12/5，前五学期均分 91.5+，两次国奖
> + **其他背景**：服役两年（南部战区陆军，获“四有优秀士兵”）；退伍复学后主动申请降级自修大一基础；主持并完成一项微波吸收方向的国家级大创
> + **推免去向/考核经历**：第一个营是长春光机所在寒假时开的（长春光机所的实力确实非常强悍，除了地理位置在长春外，其他都是很顶的）、后面参加了中科大第一期春令营并获得 B（主动联系导师，确定双选才能确定录取名额） 、参加了中科院物理所到兰大的定点面试并获得 B（没联系导师）、最后参加了北大电子学院夏令营，并确定直博。
>

## 前言
我原是 2020 级的学生，2023 年退伍复学之初，我经历过很长一段时间的焦虑：两年的学业断档、同龄人已经确定保研去向、自己连大一高数和力学都生疏了。

一路走来，我最大的体会是：**推免考核没有捷径，也不需要刻意把自己包装成不切实际的“全能天才”。** 顶尖高校的老师见多识广，他们真正看重的是**基础是否扎实、实验是否自己动手做过、面对问题是否诚实、以及是否具备踏实钻研的定力**。

写下这篇经验帖，主要梳理我在重塑学业、开展科研、准备文书和面对面试时踩过的坑与心得，希望能给基础理科、有特殊经历（当兵）或正在准备保研的学弟学妹提供一些客观、平实的参考。

---

## 一、 学业复建：如何把落下的功课补扎实？
### 1. 敢于承认断层，不走捷径
两年的军旅生活虽然磨练了意志，但对课本知识确实是完全停滞的。复学后我发现，如果直接跟班读大二，四大力学根本听不懂。所以我主动向学院申请了降级，从大一的基础课老老实实重新学起。

+ **给学弟学妹的建议**：如果你中途因为当兵、休学或转专业落下了功课，**千万不要硬撑或应付考试**。保研考核中，老师问一个简单的麦克斯韦方程组或者薛定谔方程，基础虚不虚一目了然。打牢大一大二的数理底座，后面的路才会越走越宽。

### 2. 核心专业课的复习重点
平时的期末考试拿高分固然重要，但在准备推免时，要**从“应试做题”转向“理解物理图像”**：

+ **四大力学**：重点关注物理概念的来源。比如《电动力学》中的规范变换、电磁波在分界面的边界条件；《量子力学》中的微扰论、能级劈裂机制。
+ **专业特色课**：以我的磁学方向为例，《固体物理》的能带理论、《铁磁学》的磁各向异性与畴壁理论，都是面试时高频被追问的知识点，甚至还会问兰大在磁学领域的大牛有哪些。
+ 不同院校专业对课程偏重不同，物理所以固体物理为主，中科大量子以量子力学、光学、原子物理等等。

## 二、 科研训练：大创项目如何做深、做实？
很多同学在简历上写了大创项目，但面试时老师一问具体实验参数或者机理，就答不上来。老师反感的不是本科生没做出重大成果，而是“挂名”或者“把别人的工作吹成自己的”。

### 1. 扎扎实实掌握 1-2 门核心工具
在我的大创（微波吸收材料）中，以仿真与数据分析为例：

+ **仿真软件不要只停留在跑例程**：我花了很多时间自学 CST 和 COMSOL，不仅建模型，还尝试自己去理解网格划分、边界条件设置（比如 PEC 理想电导体边界、周期性边界条件等等）以及 S11 反射参数的物理意义。
+ **掌握基本的数据处理语言**：自学 Python 或 MATLAB 处理实验导出的 S 参数和计算阻抗匹配，能引导 AI 写代码处理数据。

### 2. 实事求是：关于简历中的“极限”与“创新”
在大创结项和写简历时，我们经常会用到一些行业术语，比如材料的 Snoek 极限或吸波带宽的 Rozanov 极限。

+ **千万不要吹嘘自己“打破了物理定律”**：老师都是不同领域的行家，听到这种话第一反应是严谨性不足。
+ **正确的表述是“绕开前提假设”**：比如我在面试中被问到 Rozanov 极限时，我会老老实实跟老师解释：“Rozanov 极限的前提假设是一维平板均匀介质；我们在大创中做的是三维蜂窝超结构，引入了空间色散和多次散射，相当于通过改变结构维数绕开了原本的一维假设，并非违背因果律。” 这种严谨、诚恳的回答，反而会赢得老师的认可。

## 三、 文书准备：真诚表达，逻辑自洽
### 1. 个人陈述不要假大空，找准自己的逻辑线
写个人陈述（PS）时，最忌讳通篇堆砌豪言壮语。你需要梳理出一条**符合自身经历的内在逻辑**。  
以我为例，我的逻辑非常朴素：

+ 部队经历；
+ 退伍后做大创 $ \rightarrow $ 尝试做吸波材料减少雷达反射；
+ 做完大创后发现 $ \rightarrow $ 经典电磁学在宏观探测与隐身上确实存在物理瓶颈，因此未来想转向微观的量子精密测量（如量子磁探测）去探索更高精度的探测手段。
+ 通过调研发现$ \rightarrow $贵课题组和我所追求的方向高度契合（可以列举课题组具体成果）  
逻辑自洽，交代背景，并说明为什么想在这个方向继续深造。

### 2. 客观呈现军旅经历
有些退伍同学不知道如何写军旅经历，要么只字不提，要么写得过于军事化。

+ **正确的呈现方式**：在符合保密规定的前提下，客观说明两年的服役经历参加的一些重大活动、及所获得的荣誉，以及部队培养了你**极强的自律性、执行力以及在高强度、重复性科研任务中的耐挫力**。科研需要“坐冷板凳”，老师普遍看重学生能否顶得住实验失败的压力，这一点退伍学生或许确实有独特的心理优势，如实陈述即可。

## 四、 夏令营与面试实战：真实遇到的场景与应对
### 1. 专业面试：遇到不会的题如何处理？
在顶尖高校的面试中，被老师问倒几乎是必然的。

+ **切忌不懂装懂或胡乱猜测**：直接坦承该知识点目前确实存在盲区，但可以尝试给出自己的思考脉络，比如：“老师，这个具体的公式我目前记不清了，但我理解它的底层机制是能量守恒......，如果让我去求解，我会尝试从……切入。面试后我会立刻查阅资料补齐这一块。”
+ **态度要端正、诚恳**：面试不仅考知识储备，也在考察你面对困难时的沟通态度。

### 2. 面对“是否服从调剂”的现实问题
在夏令营中，心仪的导师非常热门、名额有限是很常见的情况。

+ **不要只回答一句简单的“服从”**：在表达服从大局的同时，最好能基于自己的学术背景，给出 1-2 个你真正了解过、且与你专业相关的备选方向（比如我在中科大面试时，提到如果量子成像没有名额，结合我的磁学背景，我也很乐意调剂到量子精密测量/磁传感方向）。这既体现了灵活性，又说明你对学院的科研布局做过功课。

### 3. 面对导师的 Offer：保持诚信，不盲目占坑
推免过程中可能会有学术大牛向你抛出橄榄枝。如果该方向与你未来的志向确实不符，**尽早、真诚、礼貌地向老师说明情况**，不要为了虚荣心“先占着坑再反悔”。学术圈真的很小，恪守诚信是对老师最基本的尊重，也是做科研的底线。

### 4. 英语面试：听懂、说清楚是第一要务
很多同学害怕英语面试，背了很多复杂的长难句，结果一紧张全忘了。

+ 真实经历来看，主要院校的英语面试要么是自我介绍，然后简单提问，或者不提问；有些学校则是只有抽取文献段落朗读一遍，并翻译；

## 五、 给学弟学妹的心态建议
1. **拒绝精神内耗，专注于当下的每一步**：保研期间看着身边同学拿各种 Offer，很容易产生焦虑。踏踏实实看懂一篇文献、推导完一个公式、做好一次仿真，比每天刷各种经验贴更有用。
2. **不卑不亢，做好双向选择**：顶尖院校的导师虽然光环很大，但选导师本质上是未来五年的合作。选择一个研究方向契合、师德良好、能真正指导你的实验室，远比单纯图名气重要。
3. **平常心面对结果**：推免是大学阶段的一次重要选择，但它绝不能定义你的一生。无论最终去到哪所学校，保持求真务实的心态和踏实干活的习惯，才是支撑你走完学术长跑的核心动力。

希望这篇平实的经验复盘能给大家带来一点点启发。祝愿各位学弟学妹在保研路上步履坚实，终有所成！
